# IntellMeet client (React + Vite + Tailwind v4)

    npm install
    cp .env.example .env   # set VITE_API_URL to your backend
    npm run dev

Routes: /login /register /dashboard /meetings /calendar /room(/:meetingId) /summaries /recordings /settings
API paths live in src/lib/api.js - edit them to match your Express routes.
